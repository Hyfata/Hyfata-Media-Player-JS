Demo 1 — Chapters: Opening / Ending Credits (English UI)

dummy1.mp4 (2 min, embedded chapters) + sample-chapters.vtt. Browsers that read embedded chapters use those, otherwise the VTT file is used. Look for the breaks on the progress bar and the skip button.

Demo 3 — No chapters

dummy3.mp4 (1 min), no chapters. Videos without opening/ending segments show no skip button or bar breaks.

Language switching

English is the default. Pass lang for a built-in pack, or override single strings with labels. See README for VideoPlayer.addLang().

new VideoPlayer('#player', { src: 'video.mp4', lang: 'ko' });

new VideoPlayer('#player', {
  src: 'video.mp4',
  labels: { skipOpening: 'Skip intro' }
});
